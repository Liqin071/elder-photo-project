# 小程序适配部署说明

> 对象:阿里云服务器上的 `elder_photo_project` 后端(FastAPI + MariaDB)。
> 前提:前端交付包已切真实后端(六个 `USE_MOCK_*` 均为 `false`,`BASE_URL = http://60.205.13.93:8000/api`)。
> 原则:本仓库改动**只做纯增量迁移,不触碰数据库里现有数据**。

## 二、部署步骤(服务器上执行)

### 1. 更新代码

```bash
cd /home/elder_photo_project && git pull
# 或:用 rsync/scp 把本地 backend 目录覆盖到 /home/elder_photo_project/backend
```

### 2. 安装依赖(如需)

```bash
cd /home/elder_photo_project/backend
pip3 install -r requirements.txt
```

### 3. 配置环境变量(backend/.env)

```bash
cat >> .env <<'EOF'
SECRET_KEY=<随机长字符串,如 openssl rand -hex 32>
WX_APPID=wxf8a7bb75e6cfc680
WX_SECRET=<小程序 AppSecret,公众平台-开发管理-开发设置>
EOF
```

> AppSecret 只放服务器,不要进代码仓库。`config.py` 用 dotenv 自动加载 `.env`。

### 4. 跑增量迁移(关键,纯新增列,不动数据)

```bash
cd /home/elder_photo_project/backend
python3 migrate_miniprogram.py
```

看到 `OK` 即通过;出现 `SKIP` 请查看原因(MariaDB 才支持 `ADD COLUMN IF NOT EXISTS`,若服务器是 MySQL 需手工执行对应 ALTER 一次)。

### 5. 重启服务

```bash
pkill -f uvicorn
cd /home/elder_photo_project/backend
nohup python3 -m uvicorn app:app --host 0.0.0.0 --port 8000 > /tmp/app.log 2>&1 &
tail -20 /tmp/app.log
```

### 6. 自检(任意机器)

```bash
# 登录(李小明等既有账号)
curl -s -X POST http://60.205.13.93:8000/api/auth/login -H "Content-Type: application/json" -d '{"username":"李小明","password":"<密码>"}'
# 带 token 拉家人卡片 / 时间轴 / 照片
curl -s http://60.205.13.93:8000/api/family/parents -H "Authorization: Bearer <token>"
curl -s "http://60.205.13.93:8000/api/timeline/years?elderId=2" -H "Authorization: Bearer <token>"
curl -s "http://60.205.13.93:8000/api/images?elderId=2&pageSize=999" -H "Authorization: Bearer <token>"
```

预期:所有响应均为 `{code:0, message:"success", data:...}`;时间字段为 `"YYYY-MM-DD HH:mm"`;无 422。

## 三、小程序侧联调配置

1. 开发者工具 → 详情 → 本地设置 → 勾选「**不校验合法域名**」(联调期必选)。
2. 微信一键登录:`wx.login` 需要后端已配置 `WX_APPID`/`WX_SECRET`;code 5 分钟有效且一次性。
3. 真机/上线:
   - 小程序后台 → 开发管理 → 开发设置 → 服务器域名:
     - request 合法域名:后端 HTTPS 域名
     - uploadFile 合法域名:同上
     - downloadFile 合法域名:后端域名(图片/语音直链 `/uploads/...` 走这里)
   - **必须 HTTPS + 已备案域名**(PROGRESS.md §八),图片 `<image>` 与语音 `createInnerAudioContext` 只认白名单域名。
4. 图片/语音直链由后端 `request.base_url` 拼出(当前为 `http://60.205.13.93:8000/uploads/...`),上线走 HTTPS 域名后自动跟随 Host。

## 七、上线配置(HTTPS + 域名,域名:guangyingliuhen.xyz)

> 现状核查(2026-08-27):`guangyingliuhen.xyz` 的 A 记录目前指向 **47.80.57.110**,
> 而后端服务器是 **60.205.13.93** —— 必须按下述步骤 1 改解析,否则 HTTPS 无法生效。

### 1. DNS 解析指向服务器(先做)

阿里云控制台 → 域名 → `guangyingliuhen.xyz` → 解析设置:

| 记录类型 | 主机记录 | 记录值 | 说明 |
|----------|---------|--------|------|
| A | `@` | `60.205.13.93` | 主域名(修改/删除现有的 47.80.57.110) |
| A | `www` | `60.205.13.93` | www 子域名 |

生效时间通常几分钟~几小时(TTL)。

### 2. 确认域名 ICP 备案

- 小程序备案 ≠ 域名备案。微信要求后端域名**已 ICP 备案**。
- 阿里云控制台 → ICP 备案 → 查询 `guangyingliuhen.xyz` 备案状态。
- 未备案:立即提交(15~20 个工作日);备案期间可继续用 IP 联调。

### 3. 申请 SSL 证书

- 备案通过后:阿里云控制台 → SSL 证书 → 申请**免费 DV 证书**(单域名,选 `guangyingliuhen.xyz`)。
- 拿到证书后,把 `xxx.pem` / `xxx.key` 上传到服务器:
  `/etc/nginx/ssl/guangyingliuhen.xyz.pem` 和 `/etc/nginx/ssl/guangyingliuhen.xyz.key`。

### 4. 服务器配 Nginx HTTPS

```bash
# 备份旧配置
cp /etc/nginx/conf.d/elder-photo.conf /etc/nginx/conf.d/elder-photo.conf.bak

# 用仓库里的模板覆盖(域名已填好)
cp /home/elder_photo_project/backend/nginx_https.conf /etc/nginx/conf.d/elder-photo.conf

nginx -t && systemctl reload nginx
```

验证:`curl -s https://guangyingliuhen.xyz/health` 应返回
`{"code":0,"message":"success","data":{"status":"healthy"}}`。

> 后端无需改代码:uvicorn 默认开启 proxy-headers,nginx 已透传
> `X-Forwarded-Proto`,接口返回的图片/语音直链会自动是
> `https://guangyingliuhen.xyz/uploads/...`。

### 5. 小程序后台配置合法域名

微信公众平台 → 开发管理 → 开发设置 → 服务器域名(三项都填同一个):

| 项 | 值 |
|----|----|
| request 合法域名 | `https://guangyingliuhen.xyz` |
| uploadFile 合法域名 | `https://guangyingliuhen.xyz` |
| downloadFile 合法域名 | `https://guangyingliuhen.xyz`(图片/语音直链) |

### 6. 前端 BASE_URL 切换(交付包唯一改动)

`交付包/utils/config.js` 第 5 行:

```js
BASE_URL: 'https://guangyingliuhen.xyz/api',
```

- 联调阶段(现在)保持 `http://60.205.13.93:8000/api` + 勾选不校验即可,上线前再切。
