**AI 供应商配置**:
```bash
# 当前生产配置:百度智能云「图像增强与特效」
AI_PROVIDER=baidu
BAIDU_API_KEY=<控制台 应用列表 → API Key>
BAIDU_SECRET_KEY=<控制台 应用列表 → Secret Key>
# 其他可选供应商:local(本地 Pillow 保底)/ ark(火山方舟豆包 SeedEdit)/ volcengine(火山视觉智能)
ARK_API_KEY=xxx            # AI_PROVIDER=ark 时必填
ARK_MODEL=doubao-seededit-3-0-i2i
AI_DAILY_LIMIT=20          # 每人每日 AI 修图次数上限(0=不限)
AI_CONTENT_MARK=1          # AI 生成内容标识开关(默认 1:写 EXIF 隐式标识 + 处理日志)
```

**百度 mode → 能力映射(2026-09 按产品语义重定义:一个 mode 可串联多个能力顺序执行)**:
| mode | 处理链路(默认) | 说明 |
|------|---------------|------|
| `restore` 老照片修复 | 图像清晰度增强 → **黑白上色(仅黑白照自动触发)** → 图像色彩增强 → 图像对比度增强 | 修模糊/褪色 + 上色 + 色彩与层次校正;最多 4 次调用 |
| `beautify` 照片美化 | 图像色彩增强 → 图像对比度增强 | 提升色彩饱和度与通透感、增层次;2 次调用 |
| `enhance` 画质增强 | 图像清晰度增强 | 清晰化 + 2 倍超分;1 次调用 |
| `colorize` 黑白上色 | 黑白图像上色 | 单独上色;1 次调用 |

> **为什么不是"图像修复(inpainting)"**:百度 `inpainting` 需指定修复区域(水印坐标),无法整图自动修复,故"修复"环节由**图像清晰度增强**承担(含超分与细节恢复)。
> **自动上色保护**:链路里的 `colourize:auto` 会先判断图片是否接近黑白(HSV 饱和度均值 < 阈值,默认 28),彩色照片**跳过上色**,避免把彩色照改色;阈值可用 `BAIDU_GRAY_THRESHOLD` 调整。
> **实测耗时/效果**:黑白照 restore ≈13s(4 次调用)、彩色照 restore ≈7s(3 次)、beautify ≈4s、enhance ≈2s、colorize ≈2.4s(前端 timeout 120s、Nginx 120s 均足够)。

覆盖映射(改 env 即可,无需改代码;逗号分隔按顺序执行):
```bash
BAIDU_EP_RESTORE=image_quality_enhance,colourize,color_enhance,contrast_enhance   # 强制黑白照也上色(去掉 :auto)
BAIDU_EP_BEAUTIFY=dehaze,color_enhance,contrast_enhance                          # 发灰照片先加去雾
BAIDU_EP_ENHANCE=image_quality_enhance,contrast_enhance                          # 画质增强再加对比度
BAIDU_GRAY_THRESHOLD=35                                                          # 灰度判定更宽松
```
**成本提示**:一次"老照片修复"最多消耗 **4 次百度调用**(黑白照),美化 2 次;`AI_DAILY_LIMIT` 按"用户操作次数"计数(默认 20 次/人/日),如按调用量计费需据此估算,并建议在百度控制台设置消费提醒/上限。
> 鉴权:API Key + Secret Key 换 access_token(有效期 30 天,内存缓存,失效自动重取);
> 常见错误码已映射中文提示(额度用尽/权限未开通/请求过频等),一切失败走业务信封,前端自动降级原图上传。
> **实测(2026-09)**:四 mode 均调通;`colourize` 上色效果显著(模拟老照片实测色彩饱和度 46→136);
> 清晰度增强含 2 倍超分。老照片"划痕/破损修补"需生成式模型(ark 分支),百度该产品线不含此能力。

## 七、上线配置(HTTPS + 域名,域名:guangyingliuhen.cn)

### 2. 确认域名 ICP 备案

- 小程序备案 ≠ 域名备案。微信要求后端域名**已 ICP 备案**。
- 阿里云控制台 → ICP 备案 → 查询 `guangyingliuhen.cn` 备案状态。
- 未备案:立即提交(15~20 个工作日);备案期间可继续用 IP 联调。

### 3. 申请 SSL 证书

- 备案通过后:阿里云控制台 → SSL 证书 → 申请**免费 DV 证书**(单域名,选 `guangyingliuhen.cn`)。
- 拿到证书后,把 `xxx.pem` / `xxx.key` 上传到服务器:
  `/etc/nginx/ssl/guangyingliuhen.cn.pem` 和 `/etc/nginx/ssl/guangyingliuhen.cn.key`。

### 4. 服务器配 Nginx HTTPS

```bash
# 备份旧配置
cp /etc/nginx/conf.d/elder-photo.conf /etc/nginx/conf.d/elder-photo.conf.bak

# 用仓库里的模板覆盖(域名已填好)
cp /home/elder_photo_project/backend/nginx_https.conf /etc/nginx/conf.d/elder-photo.conf

nginx -t && systemctl reload nginx
```

验证:`curl -s https://guangyingliuhen.cn/health` 应返回
`{"code":0,"message":"success","data":{"status":"healthy"}}`。

> 后端无需改代码:uvicorn 默认开启 proxy-headers,nginx 已透传
> `X-Forwarded-Proto`,接口返回的图片/语音直链会自动是
> `https://guangyingliuhen.cn/uploads/...`。

### 5. 小程序后台配置合法域名

微信公众平台 → 开发管理 → 开发设置 → 服务器域名(三项都填同一个):

| 项 | 值 |
|----|----|
| request 合法域名 | `https://guangyingliuhen.cn` |
| uploadFile 合法域名 | `https://guangyingliuhen.cn` |
| downloadFile 合法域名 | `https://guangyingliuhen.cn`(图片/语音直链) |
